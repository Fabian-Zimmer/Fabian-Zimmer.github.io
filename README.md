# Fabian-Zimmer.github.io

My personal website, built with [Hugo](https://gohugo.io/) on the [Toha](https://github.com/hugo-toha/toha) theme. Some of the theme's layout, animations, labels, and its filtering and highlighting features have been modified.

## Purpose
- A place to learn the syntax and configuration of Hugo, Go modules, YAML and a uv-managed toolchain.
- A record of my education, experiences, projects and skills.
- Importantly for me: a home for my personal writings on topics I care about and study in my free time.

## Theme
Toha has an [example site](https://hugo-toha.github.io/) and [documentation](https://toha-guides.netlify.app/posts) for getting started.
